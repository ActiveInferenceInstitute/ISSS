# Security Policy

This repository contains research software distributed under the MIT License
with no security guarantees. It is provided as-is.

## Reporting a vulnerability

Please report security issues privately through GitHub's Security Advisories
feature: open this repository on GitHub, go to the **Security** tab, and
select **Report a vulnerability**. Do not open a public issue for security
problems.

## Scope

The pipeline downloads and processes documents from
`https://web3.isss.org`; it requires no credentials and stores no secrets.
If you find a way in which it mishandles untrusted content (for example, a
malicious document or page), please report it through the channel above.
